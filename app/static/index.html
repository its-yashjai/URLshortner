FastAPI + PostgreSQL + Redis. Run locally with Docker Compose, it serves 3 app copies behind Nginx.

1. Shorten a link

Creates a random, non-guessable 7-character code.

2. Send test clicks

Clicks the short link many times at once. Each click is counted in Redis, and the counts are saved to Postgres in one batch every 2 seconds.

– total clicks on this link (from /stats)

3. Which copy answered?

Sends requests through Nginx and shows which app copy handled each one. With round-robin, the bars should come out about equal.

4. Benchmark: v1 vs v2

Fires the same number of clicks at the v1 path (every click is a Postgres write) and the v2 path (cached lookup, click counted in Redis), then compares speed.

Runs from your browser, so it measures the whole trip (your network + the server). Browsers open only about 6 connections per site over HTTP/1.1 (HTTP/2 shares one connection), so this is a live demo, not a lab test. The resume numbers come from the autocannon load tool. On the free hosting plan the first run after a quiet spell includes wake-up time, so run it twice.
